# 챕터3 설계 — 아직 식지 않은 자리

작성: 2026-10-01 · 상태: 사용자 구현 설계 승인 완료, 구현 계획 작성

## 1. 목적과 승인 범위

초등학교 5학년이 3단원 ‘열과 우리 생활’을 정리하면서, 하나를 찾는 미스터리에 참여한다. 사용자는 앞서 제안한 공포 이야기의 구현을 요청했고, 챕터1 UI 재사용·방탈출식 사물 조사와 도구 사용·단순 선택 문제 축소·카툰 배경 유지를 명시했다. 하나는 얼굴, 몸, 실루엣으로 직접 등장하지 않는다. 녹음과 수첩의 발신자도 확정하지 않는다.

이번 문서는 이야기 재승인이 아니라 조작과 저장, 화면, 검증 범위를 구체화한다. 기존 세계관 문서의 옛 3편 줄거리보다 이번 사용자 승인안이 우선한다. 검은 우비의 정체와 최종 결말은 이번 편에서 공개하지 않는다.

## 2. 구현 접근

기존 app.js 대화 엔진과 챕터1의 인물·큰 선택창을 재사용한다. 새 챕터의 장면 데이터, 실험 규칙, 실험 화면은 별도 모듈로 분리한다. 챕터2 전용 렌더러에 3편 조건을 덧붙이지 않는다.

검토한 대안:
- 챕터2 전용 화면 확장: 빠르지만 날씨 상태와 3편 저장이 얽히므로 제외.
- 완전히 별도 게임: 기존 저장·기록·음악·잠금과 중복되므로 제외.
- 선택한 방식: 공통 대화 엔진 + 3편 전용 순수 상태 규칙과 활동 화면. 기존 정적 실행 방식을 유지한다.

새 의존성이나 빌드 도구를 추가하지 않는다. `prototype/index.html` 직접 실행도 유지한다. 기존 자산은 덮어쓰지 않는다. 배포와 GitHub 업로드는 이번 범위에 포함하지 않는다.

## 3. 이야기와 장소 전환

현재 2편 결말은 1999년 12월 28일 낮 12:10이다. 3편도 같은 순간에 시작한다. 밤으로 갑자기 바꾸지 않는다. 겨울의 흐린 낮, 불이 꺼진 실내와 복도 안쪽의 어둠을 사용한다.

| 구간 | 사건과 플레이 목적 | 다음 장소로 가는 이유 |
|---|---|---|
| 편집실 | ‘뒤돌아보지 마’ 뒤 의자 소리. 소미의 대답이 뒤에서 한 번 더 들린다. 모니터/친구/교사 중 행동 선택 | 들어온 교사가 젖은 손수건을 보고 과학실의 수업 물건임을 알아봄 |
| 복도 | 교사가 다른 교사에게 수색을 부탁하고 아이들과 동행. 이동 장면과 목적을 대사로 명시 | 손수건 주인과 수업 흔적 확인 |
| 과학실 앞쪽 | 컵, 온도계, 따뜻한 물그릇을 조사. 온도가 사람의 존재 증거인지 확인 | 공책에 방금 태오가 한 말이 나타남. 옆 실험대의 종이 그림자가 움직임 |
| 과학실 옆 실험대 | 나선 종이와 금속판의 현상을 확인. 설명되는 현상 뒤 설명되지 않는 그림자 변화 | 수첩에 ‘아까 대답한 건 내가 아니야’가 나타남 |
| 과학실 출입문 | 교사는 먼저 복도로 나가 관리 담당자를 부름. 아이들이 따라 나가려는데 문이 닫히며 손잡이가 헛돎. 밖에서 두 종류의 교사 목소리가 들림 | 실제 교사가 관리 담당자와 돌아와 문을 열고 보건실로 동행 |
| 보건실 | 손수건과 담요 대여 기록을 확인. 전등 아래 물건이 따뜻해진 이유를 조사 | 대여 기록에 ‘작은 방송실’이 있음. 수첩에도 같은 장소가 적힘 |
| 보건실 포장대 | 보건 선생님 부탁으로 방송실에 빌려 준 보냉 상자를 회수할 준비. 냉찜질 팩의 운반 포장을 비교 | 확인된 대여 기록을 따라 교사와 작은 방송실로 이동 |
| 작은 방송실 | 담요가 걸린 빈 의자, 보냉 상자, 녹음기 조사. 상자 바깥 밑면에 붙인 봉투에서 테이프 발견 | 테이프 확보 → 재생 → 수첩의 ‘재생을 멈춰’와 충돌 |
| 결말 | ‘나는 너희 이름을 몰라. 내 목소리로 이름을 부르면 대답하지 마.’ 문밖에서 ‘태오야.’ | 목소리의 기록은 확보했지만 발신자는 미확인. 다음 편 예고 |

### 기존 제안의 개연성 보완

- 테이프를 차갑게 보관해야 한다는 잘못된 인상을 피한다. 테이프는 보냉 상자 **바깥 밑면의 봉투**에 숨겨져 있으며, 단열은 냉찜질 팩 운반에 사용한다.
- 손수건만 보고 교사가 하나를 확실히 기억한다고 단정하지 않는다. 수업 물건과 대여 기록을 알아보는 것으로 제한한다.
- 교사는 고장 난 문을 물리적으로 수리한다. 과학 정답이 자물쇠를 마법처럼 열지 않는다.
- 녹음은 우선 자막과 테이프 효과음으로 구현한다. 성우 음성이 있다고 표현하지 않는다.

## 4. 학습 활동의 조작 명세

모든 활동은 한 번에 현재 단계만 보인다. 기본 흐름은 관찰 → 예상/계획 → 실행 → 결과 확인 → 짧은 인물 대화다. 틀린 예상도 관찰 결과를 보고 수정할 수 있다. 핵심 조작에는 드래그와 동일한 ‘물건 선택 후 대상 누르기’를 모두 제공한다.

### A. 컵의 온도 측정

- 배경에서 온도계를 집어 가방에 넣고 컵을 조사한다.
- 확대 화면에서 알코올 온도계의 높이를 조절해 액체샘을 물 안에 넣는다. 물 밖, 바닥 접촉 상태는 피드백을 주고 측정 완료로 처리하지 않는다.
- ‘눈금이 멈출 때까지 관찰’로 액주가 안정되는 모습을 확인한다. 중간에 닫아도 올바른 상태로 재개한다.
- 눈금 그림을 보고 숫자 다이얼로 측정값을 기록한다. 단위 ℃는 화면에 고정한다. 숫자 정답은 액주 표시와 반드시 같은 데이터에서 생성한다.
- 완료 보상은 측정 기록. ‘누가 언제 있었는지는 아직 모른다’는 대화로 추측과 사실을 분리한다.

### B. 두 물의 온도 변화

- 따뜻한 물그릇과 차가운 물이 든 작은 금속 컵을 그림으로 제공한다.
- 두 온도 그래프의 예상 끝점을 각각 위/아래로 움직여 예측한다. 시작값과 ‘정확한 최종 온도 계산 문제가 아님’을 명시한다.
- 교사가 놓은 컵의 시간 경과를 실행하면 따뜻한 쪽은 내려가고 차가운 쪽은 올라가는 모형 기록을 보여 준다.
- 두 물체를 차례로 눌러 열 이동 화살표를 연결한다. 높은 온도 → 낮은 온도 방향을 확인하면 완료.
- 실험 수치는 교육용 모형값이다. 열평형 용어와 단순 평균 계산을 요구하지 않는다.

### C. 금속판의 열 이동 경로

- 굽은 연속 금속판, 가열 위치, 세 관찰 위치가 보이는 확대 그림.
- 관찰 위치를 순서대로 눌러 변화 예상 순서를 놓는다. 선택 순서 번호와 되돌리기를 제공한다.
- 교사 가열을 실행하면 열에 반응하는 색 변화가 연결된 판을 따라 이동한다. 실제 고온 금속을 아이가 만지는 동작은 없다.
- 예상과 결과를 비교하고 순서를 수정하면 끝난다. 잘못된 예상으로 열이 잘못 흐르는 애니메이션을 만들지 않는다.
- 별도 떨어진 판까지 전도로 건너뛰는 오개념을 피한다. 공기를 통한 다른 전달까지 없다고 단정하지 않는다.

### D. 움직이는 나선 종이

- 나선 종이, 창문, 안전 덮개가 있는 난방 장치가 보인다.
- 창문 닫기/교사에게 난방 조절 부탁하기를 실제 장면 조작으로 제공하고 조작 이력을 유지한다.
- 한 조건씩 바꾼 비교 기록이 필요하다. 두 조건을 동시에 바꾸면 원인을 구분할 수 없다고 안내한다.
- 종이의 움직임 변화 관찰 후 위·가운데·아래 연결점을 이어 따뜻해진 공기의 이동을 표시한다.
- 액체 대류는 동일 화면의 선택 관찰 탭에서 색소 물의 이동으로 비교한다. 필수 문제를 추가하지 않는다.
- 실제 종이 정지 후 벽 그림자가 한 차례 바뀌는 공포 연출은 별도 이야기 사건이다. 대류 현상이 비정상적으로 계속된다는 과학 설명을 하지 않는다.

### E. 전등과 따뜻한 물건

- 물건, 전등, 가림판을 그림으로 제공한다. 뜨거운 전등과 가림판은 교사가 다루는 것으로 명시한다.
- 전등을 켜 둔 같은 조건에서 가림판 없음/있음의 온도 변화 기록을 각각 관찰한다.
- 전등과 물체 사이에 가림판을 옮기고, 빛을 받는 부분의 시각 변화와 기록 차이를 확인한다.
- ‘닿아 있지 않아도 빛에 의해 열이 전달될 수 있다’를 짧게 정리한다. 가림판이 모든 열 이동을 완전히 막는다고 표현하지 않는다.

### F. 냉찜질 팩 운반 포장

- 기준 용기와 학생이 구성하는 용기를 나란히 둔다. 천/공기층 포장재/금속판, 뚜껑, 틈 상태를 조작한다.
- 팩의 처음 온도와 크기, 용기, 실내 온도, 비교 시간은 동일하게 고정해 조건 혼동을 줄인다.
- 실행 전 어느 쪽이 더 천천히 따뜻해질지 온도 표시를 배치해 예상한다.
- 비교 결과를 두 온도계와 짧은 기록으로 보여 준다. 포장을 수정하고 재실험할 수 있다.
- 공기층 또는 천과 틈을 줄인 덮개를 사용한 복수 설계를 인정한다. 단열재가 냉기/열을 만든다고 설명하지 않는다.
- 완료 후 포장 재료를 챙겨 교사와 이동한다. 테이프를 얻는 별도 암호는 없다.

## 5. 탐색·선택·공포 연출

- 이야기 선택 최소 네 곳: 오프닝 대처, 과학실 조사 우선순위, 문밖 목소리 확인, 마지막 녹음 처리. 선택별 두 인물의 짧은 반응 후 공통 경로로 합류한다.
- 자유 조사 순서는 허용하되 필요한 물건이 없으면 ‘먼저 무엇을 확인해야 하는지’ 인물 말풍선을 표시한다. 단서를 뒤늦게 발견해 대사가 역순으로 나오지 않도록 상태 규칙으로 제한한다.
- 가방은 온도계·손수건·수첩·포장 재료·테이프를 실제 획득 순서대로 표시한다. 목적 없는 아이템 조합은 넣지 않는다.
- 사물 강조는 hover/focus와 ‘둘러보기’로 제공한다. 모바일에서는 첫 터치로 이름/조사 행동을 알 수 있다.
- 수첩의 새 문장과 학생의 관찰 기록은 색과 제목을 구분한다. 자동으로 나타난 문장은 ‘확인된 사실’로 등록하지 않는다.
- 갑작스러운 큰 소리, 빠른 섬광, 타이머 처벌, 추격 실패는 사용하지 않는다. 그림자 변화·중복 대답·빈 의자·목소리 모순으로 긴장감을 만든다.
- ‘연출 줄이기’를 제공하고 prefers-reduced-motion을 존중한다. 모든 소리 사건은 대사/자막으로도 이해 가능하다.

## 6. 화면과 배경

대화는 챕터1의 종이색 하단 대화창, 노란 이름표, 기존 캐릭터와 큰 가로 선택지를 사용한다. 화자는 태오·소미·1999년 담임 등 실제 인물 이름을 쓴다. 정체 불명 목소리는 소미의 인용 대사나 녹음 자막으로 처리해 하나가 현재 말하고 있다고 단정하지 않는다.

새 배경: 과학실 전체, 과학실 옆 실험대, 보건실, 작은 방송실. 기존 편집실과 복도는 재사용한다. 새 배경은 기존 카툰 애니메이션풍, 1999년 소품, 인물/글자 없는 이미지로 제작한다. 주요 조사 물체는 대화창이 덮는 하단 25% 밖에 배치한다. 문 열린 상태는 실제 그림 또는 별도 문 레이어로 표현하고 말로만 열렸다고 하지 않는다.

활동 확대 화면은 데스크톱 최대 폭 1040px, 높이 화면의 86% 이내. 장면 전체를 빈 문제 창으로 덮지 않는다. 그림은 비율 보존, 제어부·피드백·실행 버튼 영역은 고정한다. 결과 문장 길이가 달라져도 버튼이 움직이지 않는다. 모바일에서는 세로 배치와 패널 내부 스크롤을 사용한다. 배경 그림과 조사 영역은 같은 좌표계를 사용한다.

## 7. 파일과 상태 경계

- `prototype/chapter3-story.js`: 장면 데이터와 선택 분기, 배경·인물·후속 장면.
- `prototype/chapter3-state.js`: 탐색/도구/활동의 순수 상태 전이, 정답 규칙, 저장 복원 검증.
- `prototype/chapter3-view.js`: 탐색과 확대 활동 렌더링, 클릭/터치/키보드 입력, 타이머 정리.
- `prototype/chapter3.css`: 3편 전용 화면 범위 내 스타일. 기존 챕터 스타일을 광범위하게 덮어쓰지 않음.
- `prototype/assets/chapter3/`: 새 카툰 배경과 프롬프트·출처 기록.
- `prototype/app.js`, `index.html`: 장면 등록, 실험 mount/dispose, 구간 체험, 2편 결말 → 3편 연결.
- `prototype/chapter-access.js`: `chapter3-` 및 `c3-` 경로에도 0715 진도 잠금 적용. 기존 1편은 변경 없음.

3편 상태는 기존 flags 아래 독립 키 `chapter3`에 version 1로 저장한다. 필드: 현재 활동, 단계, 조사 완료 목록, 소지품, 학생 예상, 관찰 기록, 선택 이력, 수첩 문장 ID, 완료 여부. 1·2편 flags는 유지한다. 입력은 허용된 값만 복원하고 알려지지 않은 단계는 해당 활동의 안전한 시작 단계로 복구한다.

활동 상태는 조작마다 저장한다. 관찰 애니메이션 도중 새로고침하면 실행 전 상태로 돌아가 재실행하게 한다. 보지 않은 관찰 결과를 완료로 만들지 않는다. 화면을 떠날 때 모든 타이머와 이벤트를 정리한다. 더블 클릭/늦게 도착한 타이머로 중복 완료하거나 다른 장면이 바뀌지 않게 한다.

장 선택에는 3편 처음부터, 과학실 측정, 전도·대류, 보건실 복사·단열, 마지막 방송실 체험을 추가한다. 체험은 본편 저장을 덮어쓰지 않는다. 잠금 해제는 기존과 같이 페이지 세션에서만 유지한다.
